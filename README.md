# 📁 자캐 백업

친구와 함께 자캐(OC) 프로필·그림·글을 모아두는 사이트예요. 네이버 밴드처럼 각자 올리고, 서로 보고, 댓글을 달 수 있어요.
모든 내용은 이 GitHub 저장소에 저장되고 고친 기록이 전부 남아서, 실수로 지워도 되살릴 수 있어요.

사이트 주소: https://ju3236.github.io/OC_backup/

## 기능

- **캐릭터**: 프로필 표, 성격·배경 같은 자유 항목, 관계(친구 자캐로도 연결), 그림 여러 장, 테마 색
- **게시판**: 썰·설정 메모·그림 글. 등장 캐릭터를 고르면 그 캐릭터 페이지에도 보여요
- **댓글**: 캐릭터와 게시물 모두
- **누가 올렸는지**: 작성자 표시, 사람별로 걸러 보기
- 검색, 세계관·태그 필터, 다크 모드, 휴대폰 화면 지원

로그인하지 않아도 누구나 **볼 수** 있고, 올리거나 고치려면 아이디·비밀번호로 로그인해야 해요.

## 처음 설정 (저장소 주인이 한 번만)

1. 사이트 오른쪽 위 **로그인** → **처음 설정** 화면이 나와요.
2. 안내 링크로 GitHub 토큰을 만들어요.
   - **Repository access**: Only select repositories → `OC_backup`
   - **Permissions → Contents**: Read and write
   - **Expiration**: 가능한 길게
3. 토큰을 붙여넣고 내 아이디·비밀번호를 정하면 끝이에요.

## 친구 계정 만들기

로그인한 뒤 **내 정보 → 계정 관리**에서 친구 아이디와 비밀번호를 만들어 알려 주면 돼요.
친구는 GitHub 계정이 없어도 되고, 받은 아이디·비밀번호로 로그인한 뒤 **내 정보**에서 비밀번호를 바꿀 수 있어요.
한 번 로그인하면 그 기기에서는 계속 로그인돼 있어요.

## 로그인은 어떻게 동작하나요

- GitHub 토큰은 무작위 공용 키로 암호화해서 `data/accounts.json`에 저장돼요. 공용 키는 계정마다 그 사람 비밀번호로 한 번 더 암호화돼 있어요.
- 그래서 비밀번호를 아는 사람만 토큰을 꺼내 저장할 수 있어요. 토큰 원문은 저장소에 남지 않아요.
- 토큰이 만료되면 저장이 안 돼요. 관리자가 새 토큰을 만들어 **내 정보 → GitHub 토큰 교체**에 넣으면 모든 계정이 그대로 다시 쓸 수 있어요.
- 비밀번호는 너무 쉬운 걸로 정하지 마세요. 암호화된 파일은 공개 저장소에 있어서, 쉬운 비밀번호는 맞춰 볼 수 있어요.
- 관리자는 모든 글과 캐릭터를 고치거나 지울 수 있고, 다른 사람은 자기 것만 고칠 수 있어요.

## 백업

- 데이터: `data/db.json` (캐릭터, 게시물, 댓글)
- 그림: `images/<아이디>/`
- 계정: `data/accounts.json` (암호화돼 있어요)
- 사이트 **내 정보 → 백업 받기**에서 JSON 파일이나 그림까지 포함된 ZIP을 받을 수 있어요.
- 예전 버전(브라우저에만 저장)에서 만든 캐릭터는 로그인하면 **내 정보 → 예전 데이터 옮기기**로 올릴 수 있어요.

## 알아두기

- 올린 뒤 로그인하지 않은 사람에게 보이기까지 1~2분 걸릴 수 있어요. (로그인한 사람에게는 바로 보여요)
- 큰 그림은 자동으로 1600px로 줄여서 올라가요. 저장소는 1GB 정도까지 넉넉하게 쓸 수 있어요.
- 저장소가 **공개(Public)** 상태여야 사이트와 그림이 보여요.

## 파일 구조

```
index.html          페이지 뼈대
css/style.css       스타일
js/config.js        데이터를 저장할 저장소 설정
data/accounts.json  계정 (암호화된 토큰)
js/app.js           사이트 동작
data/db.json        모든 글·캐릭터 데이터
images/             올린 그림
```
