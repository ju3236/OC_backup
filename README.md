# 📁 자캐 백업

친구와 함께 자캐(OC) 프로필·그림·글을 모아두는 사이트예요. 네이버 밴드처럼 각자 올리고, 서로 보고, 댓글을 달 수 있어요.
모든 내용은 이 GitHub 저장소에 저장되고 고친 기록이 전부 남아서, 실수로 지워도 되살릴 수 있어요.

사이트 주소: https://ju3236.github.io/OC_backup/

## 기능

- **캐릭터**: 프로필 표, 성격·배경 같은 자유 항목, 관계(친구 자캐로도 연결), 그림 여러 장, 테마 색
- **게시판**: 썰·설정 메모·그림 글. 등장 캐릭터를 고르면 그 캐릭터 페이지에도 보여요
- **댓글**: 캐릭터와 게시물 모두
- **누가 올렸는지**: 작성자 표시, 사람별로 걸러 보기, 사이트용 닉네임
- 검색, 세계관·태그 필터, 다크 모드, 휴대폰 화면 지원

로그인하지 않아도 누구나 **볼 수** 있고, 올리거나 고치려면 로그인해야 해요. 자기 글·캐릭터·댓글만 고치고 지울 수 있어요.

## 친구 초대하기 (저장소 주인이 한 번)

1. 저장소 **Settings → Collaborators → Add people**
2. 친구의 GitHub 아이디를 넣고 초대
3. 친구는 메일이나 GitHub 알림에서 **초대를 수락**

## 로그인하기 (각자, 기기마다 한 번)

1. 사이트 오른쪽 위 **로그인** 누르기
2. 안내에 있는 **토큰 만들기** 링크 → Expiration을 넉넉히(1년 또는 No expiration) 고르고 **Generate token**
3. `ghp_`로 시작하는 토큰을 복사해서 붙여넣기

토큰은 그 기기 브라우저에만 저장돼요. 다른 사람이 쓰는 기기에서는 다 쓴 뒤 로그아웃하세요.
토큰이 유출되면 GitHub **Settings → Developer settings → Personal access tokens**에서 지우고 새로 만들면 돼요.

## 백업

- 데이터: `data/db.json` (캐릭터, 게시물, 댓글, 닉네임)
- 그림: `images/<아이디>/`
- 사이트 **내 정보 → 백업 받기**에서 JSON 파일이나 그림까지 포함된 ZIP을 받을 수 있어요.
- 예전 버전(브라우저에만 저장)에서 만든 캐릭터는 로그인하면 **내 정보 → 예전 데이터 옮기기**로 올릴 수 있어요.

## 알아두기

- 올린 뒤 로그인하지 않은 사람에게 보이기까지 1~2분 걸릴 수 있어요. (로그인한 사람에게는 바로 보여요)
- 큰 그림은 자동으로 1600px로 줄여서 올라가요. 저장소는 1GB 정도까지 넉넉하게 쓸 수 있어요.
- 저장소가 **공개(Public)** 상태여야 사이트와 그림이 보여요.

## 파일 구조

```
index.html          페이지 뼈대
css/style.css       스타일
js/config.js        데이터를 저장할 저장소 설정
js/app.js           사이트 동작
data/db.json        모든 글·캐릭터 데이터
images/             올린 그림
```
