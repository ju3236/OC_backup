# 📁 자캐 백업

자캐(OC) 프로필, 설정, 관계, 그림을 한곳에 모아두는 정적 웹사이트입니다.
빌드 과정 없이 `index.html`을 열기만 하면 동작하고, GitHub Pages로 바로 배포할 수 있어요.

## 기능

- **캐릭터 목록**: 썸네일 카드, 이름·태그·설명 검색, 세계관/태그 필터
- **상세 페이지**: 대표 이미지, 프로필 표, 성격·배경 등 자유 항목, 관계(다른 캐릭터로 링크), 갤러리(클릭하면 크게 보기)
- **브라우저에서 편집**: 추가/수정/삭제, 이미지 업로드(자동으로 줄여서 저장) 또는 이미지 주소 입력, 캐릭터별 테마 색
- **백업 / 복원**: 전체를 JSON 파일 하나로 내보내기·불러오기(합치기/덮어쓰기), 캐릭터 하나만 내보내기
- 라이트/다크 모드, 모바일 화면 지원

## 데이터는 어디에 저장되나요?

| 위치 | 설명 |
|---|---|
| `data/characters.js` | 사이트 기본 데이터. 저장소에 커밋되므로 누가 어디서 접속하든 보입니다. |
| 브라우저(IndexedDB) | 사이트에서 편집하면 그 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 사라져요. |

편집한 내용을 **영구 보관**하려면:

1. 사이트의 **[백업 / 복원] → "백업 파일 받기 (.json)"** 로 받은 파일을 클라우드 등에 보관하거나,
2. **"사이트 데이터 파일 받기 (characters.js)"** 로 받은 파일로 저장소의 `data/characters.js`를 교체하고 커밋하세요.

> 업로드한 이미지는 데이터 안에 함께 들어가서 파일이 커질 수 있어요. 그림이 많다면 이미지를 `images/` 폴더에 넣고 편집 화면에서 `images/파일명.png`처럼 주소로 추가하는 방법을 추천해요.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`, 브랜치와 `/ (root)` 폴더 선택 후 저장
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속

## 파일 구조

```
index.html            페이지 뼈대
css/style.css         스타일
js/app.js             사이트 동작 (목록·상세·편집·백업)
data/characters.js    기본 캐릭터 데이터
images/               직접 넣는 그림 파일 (선택)
```
